#### 🎧 STRIX — Audio Classification System
Fusion de 3 datasets audio publics (MAD, ESC-50, DroneAudioDataset) → pipeline ML complet de la donnée brute au déploiement embarqué.

| | Lien | Détails |
|---|---|---|
| 📦 Dataset | [`STRIX_3_dataset_merged`](https://huggingface.co/datasets/Newton2676/STRIX_3_dataset_merged) | 59 classes · ~10 800 clips |
| 🤖 Modèle lourd | [`STRIX_heavy_model`](https://huggingface.co/Newton2676/STRIX_heavy_model) | AST · 86.2M params · **96.4% accuracy** |
| 🔬 Modèle embarqué | [`STRIX_STM32_model`](https://huggingface.co/Newton2676/STRIX_STM32_model) | DS-CNN · TFLite INT8 · ~144 KB · STM32F4/F7 |
| 🖥️ Demo live | [`demo-audio-classifier`](https://huggingface.co/spaces/Newton2676/demo-audio-classifier) | Gradio Space |

`Python` `PyTorch` `TensorFlow` `Transformers` `TFLite` `STM32Cube.AI`
